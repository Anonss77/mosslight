**Mosslight is a 3D wave-survival action game.** Play as Neri, a lantern mage, and survive 8 waves across 3 living worlds — Bloomroot Warrens, Cinderglass Works, and the Moonmilk Vault — then defeat the boss, the Gloam Bell, to win.

Pick one of 3 heroes, each with their own weapon, 3 unique skills and an ultimate:

- **Neri, the Lantern Mage** — fireballs, Ember flames, Starfall meteors
- **Aldric, the Knight** — sword slashes, a charging lunge, Whirlwind tornado
- **Lyra, the Ranger** — arrows, a 5-arrow volley, Frost burst, Moonfall meteors

Collect coins and shards from kills, chests and wave-clear bonuses. Spend coins in the intermission shop (Heart, Energy, Bomb, Magnet) and on upgrades (Bright Wick, Quick Hands, Long Thread, Padded Cape, Shard Charm). Open your bag any time to use Heart, Bomb or Magnet — opening the bag pauses the game.

## How to play

- **Move:** WASD / arrow keys, or the on-screen joystick (touch)
- **Basic attack:** J / Space, or the ATTACK button — no cooldown
- **Skill 1:** Q — **Skill 2:** E — **Ultimate:** R (needs 100 energy)
- **Bag:** B — **Mute:** M
- **Goal:** survive all 8 waves and kill the Gloam Bell before the wave timer runs out. You lose if your HP reaches 0.

## Run it

Open `game/index.html` in desktop Chrome, or serve the `game/` folder with any static HTTP server. No build step, no network requests — everything is local files.
